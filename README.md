# 進路診断アプリ（滋賀の高校生向け・一般版）

スマホで使える単一HTMLの進路診断アプリ。診断（評定・偏差値・興味・職業・地域・入試方式・RIASEC適性）から、収録185大学・1105学部を3ゾーン（実力相応/チャレンジ/安全圏）でおすすめする。

- **公開URL**: https://ganchi2014-tech.github.io/shinro-shindan-general/ （masterへpushすると約1分で自動反映。GitHub Pagesがルートを配信）
- 本体: `進路診断_v2.html`（ビルド生成物。直接編集しない）

## ビルド・テスト（Node.jsのみ。Python不要）

```
node work/build_v2ui.js      # テンプレ work/app_v2ui.html + data_v2.json → 進路診断_v2.html を生成
node work/test_engine_v2.js  # エンジンのテスト（ALL OK が出れば緑）
node work/test_bridge_v2.js
node work/test_agg_v2.js
node work/test_guide_v2.js   # 資格の判定・通学時間・向いていそうな分野
node work/check_v2.js        # データ検収（CHECK PASS）
```

ローカル確認は任意の静的サーバで `進路診断_v2.html` を開く（例: `npx http-server -p 8899`）。

## 作業履歴（2026-11）高2・12月配布に向けた改修（ブランチ `feat/2nen-12gatsu`）

「滋賀の高校生が欲しい情報に届くか」を生徒像6通りで通して見直した結果の改修。

| 何を | どう変えたか |
|---|---|
| 仕事を選んだときの結果 | 「医療・福祉」など大きな系統に寄せるだけだったのを、**その仕事の資格が取れる学部を上段**に、近い分野は「資格は要確認」でたたむ形に（看護師を選んで薬学部が並ぶ問題の解消）。資格が決め手の15職種が対象。中高教員は対象外 |
| 大学以外の道 | 仕事ごとに専門学校・短大・高卒採用の道を**種類別に**案内（個別の学校は載せない方針）。通学圏に資格が取れる大学が0のときはそう言い切る |
| 通学 | 「滋賀から○分」は起点が大学ごとに違っていた（大津/草津/米原/不明）。**出発駅を7つから選び**、京都駅・米原駅までの時間を足す方式に。学部のキャンパス（立命館BKC/OIC/衣笠など）も反映。足切りはやめ、上限を20分まで超える学部は件数つきでたたむ |
| 未定の生徒 | 仕事も分野も空のとき、12問の答えから**向いていそうな分野3つ**を根拠つきで表示。答えていなければ12問へ誘導。「高2の今、次にやること」を結果に追加 |
| 表示 | 「適性 38」の点数は廃止（並び順には使う）し理由の札に。国公立の+8は言葉で説明。Step4は「卒業後に働きたい地域」と明記 |
| 費用 | 自宅通学向きの15大学で、下宿4年間が自宅生の生活費で計算されていた誤りを修正（他大学の中央値を当てた目安と明記） |
| データ | 県内2校を追加（推定データ）。滋賀県公表の県内就職率を25校に追加（進路タブ） |

**数字の出どころと限界**
- 駅から駅の時間はJR新快速の時刻表（2026年秋）。堅田・貴生川と、駅から大学までの時間は概算。乗り換え待ちは含まない
- 京都駅・米原駅から各大学までの時間は、既存の「滋賀から○分」から起点ぶんを引いて出している（大学ごとの実測ではない）→ 精度を上げるなら `guide_v2.js` の `campusBase` を大学ごとの実測値に置き換える
- 専門学校などの年数は養成課程の一般的な枠組み。配布前に進路指導室で文面を確認すること

詳細な経緯・レビュー指摘・実装方針は各コミットメッセージと計画docに記録。

## データ品質の方針

- `data_status`: verified（出典+検証日あり）/ estimated（推定。アプリが推定バナー表示）/ unconfirmed（未確認警告）
- 推定値には「（要確認）」を付け、日程・年度別倍率・ゼミは出典なしでは載せない（merge_v2_add.jsが機械的に排除）
- 後追い検証: パスナビ等で調査 → `work/research/<uni>.json` → `node work/merge_research.js` でマージ（差分がdocs/data-verificationに記録される）
